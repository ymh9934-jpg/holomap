# 서부교회 홀로맵 (3D 층 안내도)

갤럭시 탭 S8+용 새가족 안내 앱입니다. 홀로그램 설계도 느낌의 3D 건물을 돌려 보고, 층을 눌러 펼치고, 방을 눌러 설명을 볼 수 있어요.

- 화면 코드: `web-app.html` (맨 위 `FLOORS` 부분만 고치면 층·방 이름과 설명이 바뀝니다)
- main 브랜치에 올리면 GitHub Actions가 APK를 만들어 Releases에 올립니다.
- 처음 한 번 저장소 Settings → Secrets and variables → Actions 에 `SIGNING_PASSWORD`를 넣어야 합니다.
